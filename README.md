# مستشفى الخيري — Patient Data Manager

برنامج تسجيل بيانات المرضى للأستاذ / مستر بدوي.

## المميزات

- **إدخال بيانات المريض**: الاسم، العمر، الجنس، الشكوى
- **حفظ دائم**: البيانات تُحفظ في ملف `patients.json` بجانب البرنامج
- **بحث فوري**: ابحث بالاسم أو العمر أو الجنس أو الشكوى
- **تعديل وحذف**: مع تأكيد قبل الحذف
- **طباعة**: زر طباعة لكل مريض مع ترويسة قابلة للتخصيص (اسم المستشفى، العنوان، رقم الهاتف)
- **واجهة عربية**: RTL، تصميم داكن

## التقنيات

- Python HTTP server (standard library)
- HTML / CSS / JavaScript (frontend)
- PyInstaller (تجميع في ملف exe)

## طريقة التشغيل

### من الكود
```bash
python app.py
```
ثم افتح المتصفح على `http://localhost:17755`

### من ملف exe
ضغطة مزدوجة على `PatientManager.exe` — يفتح المتصفح تلقائياً.

## الملفات

| الملف | الوصف |
|---|---|
| `app.py` | الكود الكامل (سيرفر + HTML مدمج) |
| `server.py` | نسخة السيرفر منفصلة (للتطوير) |
| `index.html` | الواجهة منفصلة (للتطوير) |
| `start.bat` | مشغل سريع |
| `launch.vbs` | مشغل صامت |

## بناء ملف exe

```bash
python -m PyInstaller --onefile --noconsole --name PatientManager app.py
```
